# 答案(并联电路 · 欧姆定律与电功率 · 计算题)

> 来源:网传「2025 年安徽省中考物理卷(及答案)」第 19 题(renrendoc.com/paper/492149216.html);疑为改编卷,数据自洽。图中 R1 与 R2 并联,电流表串在 R1 支路,测 R1 电流。

(1)R1 与 R2 并联,U = U1 = I1R1 = 0.3 A × 20 Ω = 6 V。
(2)I2 = U / R2 = 6 V / 30 Ω = 0.2 A。
(3)干路电流 I = I1 + I2 = 0.3 A + 0.2 A = 0.5 A,总功率 P = UI = 6 V × 0.5 A = 3 W。
