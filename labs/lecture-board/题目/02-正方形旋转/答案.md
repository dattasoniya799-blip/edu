# 答案(正方形与等腰直角三角形旋转 · 综合与探究)

> 来源:由协调会话按题意推导(坐标法核算),用户未另给标准答案;识题时以此为准,若与模型自算不符须标注「与答案不符,请核对」。
> 设定:正方形边长 15,AE=AF=9,∠EAF=90°;△AEF 绕 A 逆时针旋转 α(0°<α<90°)得 △AE′F′。

(1)BE′ = DF′。
理由:AB=AD,AE′=AF′,∠BAE′=90°−∠E′AD=∠DAF′,故 △ABE′ ≌ △ADF′(SAS),BE′=DF′。

(2)当 AE′ ⊥ BE′ 时(此时 cos α = 3/5,sin α = 4/5):
① 证明 NA·NF′ = ND·NE′。
∠ABE′=90°−∠BAE′=∠E′AD;由 △ABE′≌△ADF′ 得 ∠ADF′=∠ABE′=∠E′AD,即 ∠NAE′=∠NDF′;又 ∠ANE′=∠DNF′(对顶角),故 △NAE′ ∽ △NDF′,NA/ND=NE′/NF′,即 NA·NF′=ND·NE′。
② S△AEM : S△AFM = 4 : 3。
思路:AE=AF=9,两三角形共边 AM,面积比 = sin∠EAM : sin∠FAM;AE′⊥BE′ 时 tan∠E′AD=3/4,AM 与 AB 夹角 ∠EAM 满足 sin∠EAM=4/5、sin∠FAM=3/5,比值 4/3。(坐标核算:A(0,15)、M(15,3.75),S△AEM=67.5,S△AFM=50.625。)
