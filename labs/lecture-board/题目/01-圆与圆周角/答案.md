# 答案(圆与圆周角)

> 来源:由协调会话按题意推导,用户未另给标准答案;识题时以此为准,若与模型自算不符须标注「与答案不符,请核对」。

(1)∠ADB = 65°。
思路:OA=OC → ∠OCA=∠OAC=15°;∠OCB=∠ACB−∠OCA=25°;OB=OC → ∠OBC=25°;∠ADB 是 △DBC 的外角,∠ADB=∠DBC+∠DCB=25°+40°=65°。

(2)① 证明:∠CDB=∠OBC,△CDB 中 ∠DCB=180°−∠CDB−∠DBC=180°−2∠OBC;△OBC 中 OB=OC,∠BOC=180°−2∠OBC;故 ∠ACB=∠DCB=∠BOC;同弧 BC 上 ∠BOC=2∠CAB,所以 ∠ACB=2∠CAB。

(2)② OB ⊥ BE(BE 是 ⊙O 的切线)。
思路:BE=BA → ∠E=∠BAE=∠CAB;由①∠ACB=2∠CAB,∠BCE=180°−∠ACB;△BCE 中 ∠CBE=180°−∠BCE−∠E=∠ACB−∠CAB=∠CAB;又 ∠OBC=∠OCB,∠OBC+∠CBE=∠OCB+∠CAB;结合 ∠ACB=2∠CAB 与 ∠BOC=2∠CAB,△OBC 中 2∠OBC+2∠CAB=180°,∠OBC+∠CAB=90°,即 ∠OBE=90°。
