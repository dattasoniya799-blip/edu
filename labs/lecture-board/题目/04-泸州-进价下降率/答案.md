# 答案(2025·四川泸州·中考真题 · 一元二次方程应用)

> 来源:2025 年中考数学真题分类汇编「专题09 一元二次方程及其应用」第 35 题(https://mip.21cnjy.com/P/23340309.html);答案经协调会话核算。

(1)乙种商品每件进价的年平均下降率为 20%。
设年平均下降率为 x:125(1−x)² = 80 → (1−x)² = 0.64 → 1−x = 0.8(舍去 1−x = −0.8)→ x = 0.2。
(2)最少购进 40 件甲种商品。
2024 年甲每件进价 125 − 25×2 = 75 元,乙 80 元;设购进甲 a 件,则 75a + 80(100 − a) ≤ 7800 → 8000 − 5a ≤ 7800 → a ≥ 40。
