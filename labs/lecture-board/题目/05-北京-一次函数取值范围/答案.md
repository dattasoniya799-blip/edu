# 答案(2025·北京·中考真题 第 21 题 · 一次函数与不等式)

> 来源:2025 北京中考数学真题(有答案)PDF(cdn.xschu.com);题干中的不等号在 PDF 抽取时丢失,已按官方解析(m≥2 与 m≤3)反推为「当 x<1 时」。

(1)k = 2,b = 1。将 (1,3)、(2,5) 代入 y = kx + b:k + b = 3,2k + b = 5,解得 k = 2,b = 1。
(2)2 ≤ m ≤ 3。
由(1)得 y = 2x + 1,y = x + k = x + 2。当 x < 1 时要求 mx < 2x + 1 且 mx < x + 2 对每个 x 成立:
mx < 2x + 1 ⇔ (m − 2)x < 1,x 可取任意小于 1 的值(含负数很大的),故需 m − 2 ≥ 0,即 m ≥ 2;
mx < x + 2 ⇔ (m − 1)x < 2,m − 1 > 0 时随 x 增大而增大,在 x → 1 处取上界 m − 1 ≤ 2,即 m ≤ 3;
m = 2 时 2x < 2x + 1 与 2x < x + 2(即 x < 2)在 x < 1 上恒成立。综上 2 ≤ m ≤ 3。
