## 整体气质

浅色、克制、留白充分。底色 `bg`,白卡片 + 1px `line` 边 + 轻阴影(`shadow.card`),圆角 lg 16px / md 12px。
主色靛蓝 `primary` 只用于:主按钮、激活态、关键数据。**颜色只能以令牌类名使用,禁止裸写十六进制。**

## 语义色(克制使用,每屏强调色不超过三处)

- **AI 相关一律紫 `violet`**:目前唯一在线的 AI 呈现是学生端 AI 答疑(「AI 助教·小启」面板 / 课堂 `class:ai_ask`),
  用紫标识;**没有真实 AI 在背后的东西不许套紫、不许挂「AI」字样**(2026-08-31 假功能下线的口径)。
- 激励 / 告警橙 `orange`(截止提醒、待办高亮、mock 角标)。
- 正确 / 掌握绿 `green`;错误 / 薄弱红 `red`(错题、掌握率 < 60% 的进度条)。
- 进度条:绿(≥ 80)/ 主色或橙(60–79)/ 红(< 60)。

## 布局范式

- **管理端 / 教师端**:浅色侧边栏(白底,激活项 `primarySoft` 底 + `primary` 字),topbar 58px,
  内容区 page-head(标题 + sub + 右侧 actions)→ stats 四卡 → card 列表 / 表格。
- **学生端(平板横屏,1180×820 视口走查)**:顶部 logo + 胶囊 Tab(激活 = `primary` 实底白字),
  一切可点目标 min-height ≥ 44px;课堂模式整屏接管(深色 class-head + 步进器),不挂 Shell。
- 实验区 `labs/playground` 走独立的纸感暖米白外壳(`src/experiments/shared/paper-shell.ts`),不受本节约束,
  但颜色同样只许来自令牌的语义色(剧本里只写语义色名,渲染器映射到令牌)。

## 组件规约(`@qiming/ui`)

- 表格:表头 12px `text2` 灰底;行 hover 微底色;状态用 `Tag` 胶囊(soft 底 + 语义色字)。
- 按钮:主按钮 `primary` 实底带投影;次按钮白底 1.5px `line` 边;危险操作只用文字 link danger。
- 公式:一律用 `<TexText/>`(KaTeX 混排,`$..$` 行内 `$$..$$` 块级,含 mhchem),禁止图片公式;
  公式语法错误显示红色 mono 提示。
- 题目插图:一律经 `<QuestionFigures>` / `<OssImage>` + 各端 `api.ts` 的 `resolveFigureSrc`(异步换签名直链),不直接 `<img src=ossKey>`。
- **空态 / 加载 / 错误态三分**:每个列表页必须有空态文案与骨架屏;**加载失败必须显示错误态 + 重新加载按钮**,
  不许吞成「暂无数据」(本仓反复修过的 bug 家族)。
- mock 模式右下角挂 `MockBadge`(橙色「MOCK 数据」角标),真实模式不渲染。

## 字体与字号

`font.sans` 系统中文栈;页面标题 21px/800,卡片标题 15px/700,正文 14px,辅助 12–12.5px `text2`/`text3`。
数字一律 `tabular-nums`。

## 文案口径

- 真实与 mock 必须可辨:mock 回复带「mock」字样,页面挂角标。
- 不给未兑现的承诺:课堂未就绪写「课堂未开放,请稍候」而不是放行;失败写真实原因(后端 `message`)而不是硬编码猜测。
- 已下线能力(AI 课件 / 拍照预批 / 伴学旁白 / AI 诊断)在管理端只显示「已下线」登记态,不出现可切换的假开关。
