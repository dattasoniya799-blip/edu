## 三、验收清单 B:核心闭环(约 20 分钟)

1. **管理端**:工作台数字与 DB 一致;「最近动态」是可读句子(「王校长 新建了教师 xx」);到课率显示百分数(如 100%,不是 1%);
   给 `S-0002` 重置密码拿明文。新建课程时授课教师默认「请选择」(不选会拦)。
2. **学生端**:S-0002 登录(试试输入 ` s-0002 ` 也能登)→ 今日 / 课程时间线 → 错题本有 1 条 seed 错题 → 报告。
3. **教师端**:张明 → 试卷库(有学科筛选、卷带学科 / 知识点)→ 新建试卷「保存草稿」→ 试卷库出现「草稿」并可「发布」→
   知识点内容库默认显示**数学**图谱(可切化学 / 物理)→ 资源库上传一张图 → 弹窗归档到知识点。
4. **编排 + 布置**:提高班第 5 讲 → 添加单元选知识点 → 挂载课件(刚上传的图会因同知识点置顶)→ 课后作业「选择已有卷」→ 保存 →
   **「立即布置」** → 学生端作业列表立刻出现;或「去组卷 → 发布作业」。
5. **作答 → 错题即时入账**:学生答错客观题、解答题拍照 → 交卷 → **错题本立刻出现刚答错的客观题**(不等老师出分)。
6. **批改 → 订正**:教师作业批改 → 复核页名单显示「待判分」而非「null 分」→ 打分(12/10 会被拦)→ 出分 →
   学生成绩单含「老师点评」→ 时间线该讲出现「N 道错题待订正 · 订正错题」按钮 → 点进去是只含答错客观题的订正卷(不计分)。
7. **课堂链**:教师发布讲次 → 学生「进入课堂」→ 讲解环节能看到挂的课件(图 / PDF / 互动动画 / 视频)→ 随堂练即时判分 →
   教师监控页看到 roster,**控场栏**:暂停(学生端整屏遮罩)→ 继续 → 切环节 → **下课**(确认弹窗)→ 学生端小结 + 课后任务 →
   监控页显示「课堂已结束」→ 管理端到课率有值。
8. **安全**:管理端停用一名教师 → 该教师已打开的页面下一次请求即 401 回登录页;登录提示「账号已停用」;启用后需重新登录。
   平台设置把学生使用时段改成不含当前时刻 → 学生登录 403「当前为休息时段」(按北京时间判定)→ 改回。

## 五、已知边界(验收时不要误判为 bug)

- AI 答疑无 key 时回复带 mock 字样——按设计的路由态;配 key 即真实(本机 .env 已配 DeepSeek,会花钱)。
- 批改复核页的历史 aiScore 是下线前的真实历史数据,如实展示。
- 讲次 / 课堂时间按浏览器本地时区显示(本机若非 Asia/Shanghai 会与 seed 的 14:00 不同),不是 bug;**业务判定**(学习时段)按机构时区。
- 同机构他教师能打开你的讲次编排页(用户拍板「可读」),但为只读态(无保存 / 发布按钮);批改页则提示无权限。
- 停用账号即刻 401;唯一边界是「与重置密码同一秒内签发的 token 不被吊销」(D-5,接受:严格小于是为了不误杀重置后立刻登录的新 token)。
