# 动画课堂学生端 Demo Implementation Plan

> **For agentic workers:** 本计划在当前会话内联执行(executing-plans)。不改契约、不提交,验收看 `apps/lab` 上课页。
> 需求原文:`qiming/docs/需求文档/02-动画课堂-学生端demo需求.md`

**Goal:** 实验区只留一套学生上课页,三堂坐标系课(一次函数 / 导数 / 弹簧讲题)能听、能看、指定拍能动手。

**Architecture:** 讲解剧本仍是中枢。扩展 `kind: concept | problem`,播放器只读校验通过的剧本。坐标系 Canvas 缓动引擎不动。旧 HTML 车间降为素材入口。

**Tech Stack:** React 18 + TypeScript + Zod 4 + Canvas 2D + 浏览器 TTS 占位;只动 `apps/lab`。

### Task 1: 剧本契约

- [ ] `kind: 'concept' | 'problem'`
- [ ] `concept` 必有 `goal`,无 `problem`
- [ ] `problem` 必有 `problem.text`
- [ ] `steps.min(5)`,每步 `label` 必填(2–8 字)
- [ ] 全课至少一拍有 `interaction`
- [ ] 讲稿禁「我来画」「接下来添加」
- [ ] 写 `tools/check-scripts.ts`,`node --experimental-strip-types` 可跑

### Task 2: 三份剧本

- [ ] `kp-linear-kb`:≥5 拍,先动手 k 再动手 b,八年级不用「斜率/截距」
- [ ] `kp-derivative-secant`:割线→切线,动手 Δx,公式在结论拍才出
- [ ] `math-linear-spring-1`:引入不出解析式,动手挂质量,已知 y 求 x 在后半

### Task 3: 上课页 + 课表

- [ ] 双栏;观看拍不渲染滑杆(留等高空槽,主图不跳)
- [ ] 控制:上一步 / 下一步 / 重听本拍 / 连播 / 语音;(倍速可留)
- [ ] 知识点无原题栏;讲题原题默认收起
- [ ] 无「剧本」页签、无「从头演一遍」;点当前步=重听;`?dev=1` 才显示剧本 JSON
- [ ] 实验区主入口「动画课堂」三张课卡;「知识点动画」改为 parked 素材

### Task 4: 验收命令

```
cd apps/lab
npm run check:scripts
npm run validate:anim
npm run build
```

人审:打开 http://localhost:5176/ → 动画课堂 → 三课各走一遍。
